# GLM Arcade

A retro CRT arcade cabinet as a **mobile-first PWA**: installable, works offline, zero dependencies.

**Play online:** https://itsnotalwin.github.io/glm-arcade/ (served via GitHub Pages — install straight from your phone)

Game #1 **NEON SNAKE** is playable now. BREAKOUT, INVADERS and STACKER show as locked slots — each future game is a small object added to the `GAMES` array in `index.html`.

## Play

Double-click **`play.cmd`** — it starts a tiny local server and opens `http://localhost:8137`.

(Serving over `http://localhost` is what enables PWA install + offline mode. Opening `index.html` directly also works for playing, just without those.)

## Install on this PC

Open the game in Chrome/Edge via `play.cmd`, then use the **INSTALL APP** pill on the menu screen (or the browser's install icon in the address bar). It launches in its own fullscreen window like a real arcade app.

## Install on a phone

This repo is served over **HTTPS via GitHub Pages**, so phones can install it directly:

- **Android Chrome**: open https://itsnotalwin.github.io/glm-arcade/ → menu → *Add to Home screen* / install banner
- **iOS Safari**: open the same URL → Share → *Add to Home Screen*

After the first load everything is cached — airplane mode still plays.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move snake | Arrows / WASD | Swipe anywhere, or on-screen D-pad |
| Pause | P / Esc / Space | ❚❚ button (top-right) |
| Confirm / start | Enter / Space / any key | Tap |
| Navigate menu | Up / Down | Swipe up / down, tap cards |
| Sound on/off | M | SOUND pill on menu / pause |
| Fullscreen | via FULLSCREEN pill | FULLSCREEN pill |

## Files

- `index.html` — the entire game (shell, engine, CRT effect, Snake)
- `sw.js` — service worker (offline cache; bump `CACHE` version when editing the game)
- `manifest.webmanifest` — PWA identity + icons
- `icons/` — generated by `tools/gen-icons.ps1` (PowerShell + System.Drawing, no deps)
- `server.js` / `server.py` + `play.cmd` — one-click local serving

## Adding game #2

Register a new object in `GAMES` with `{ id, name, tag, color, locked: false }` and implement
`reset()`, `update(dt)`, `draw()` following `Snake` — the shell handles menus, scores, pause,
audio and touch input.
